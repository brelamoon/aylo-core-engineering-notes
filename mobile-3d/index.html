AYLO Core · Mobile 3D

Mobile 3D performance is a budget.

A reliable viewer combines several small controls: capped device pixel ratio, one animation loop, bounded frame delta, compact lighting and explicit cleanup.

Keep a useful first frame

The static preview remains visible while the model loads. The renderer uses a transparent canvas so the viewer fits the surrounding product design. Camera fitting responds to both model bounds and card aspect ratio instead of relying on one hard-coded distance.

Interaction is part of performance

Automatic rotation pauses while a visitor drags and respects reduced-motion settings. When the component leaves the page, animation stops and WebGL resources are released instead of accumulating across navigation.

The wider page still matters. Image dimensions, carousel neighborhood size and the number of active viewers can overwhelm a well-written renderer.
