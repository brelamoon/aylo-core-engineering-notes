AYLO Core · Release boundary

A source asset is not automatically a public product.

Visual teams need room to review images, metadata and pricing before a collection becomes part of the public product. A generated image should not appear in a campaign merely because its path was imported.

One release decision

The checkout resolver, public UI and marketing campaign need to respect the same publication state. A release gate verifies that the file exists, identifiers are unique, the image format is correct, pricing is intentional and the destination page can render the item.

Communication becomes clearer

Explicit publication state keeps shipped behavior, internal review and roadmap separate. Campaign links can then reference the released catalog instead of a development directory or authenticated preview.

The official public catalog is the source of truth for current availability.
